系统功能

人员管理

维护学生学号、姓名、班级和备注，为后续人脸样本绑定人员身份。

人脸录入

支持上传图片或摄像头拍照，检测单张人脸后保存特征向量。

识别签到

通过 YuNet 检测人脸，使用 SFace 提取特征，并按余弦相似度完成匹配。

考勤导出

按人员和日期查询签到记录，并导出 CSV 用于报告和演示。

技术路线

项目参考开源人脸识别考勤系统的业务流程，但避开旧版 TensorFlow 1.x 和 dlib 依赖，使用 Python 3.11 兼容性更好的 OpenCV ONNX 深度模型。

  1. 浏览器采集图片或摄像头帧
  2. Flask 接收图片并调用识别引擎
  3. YuNet 检测人脸并完成质量过滤
  4. SFace 提取特征向量
  5. SQLite 保存人员、样本和考勤记录

本地运行完整功能

Netlify 页面用于公网展示。完整摄像头录入、OpenCV 推理和 SQLite 写入功能需要在本地 Python 环境运行。

git clone https://github.com/phantom725/FaceRecognition.git
cd FaceRecognition
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts\download_models.py
python app.py

启动后访问 http://127.0.0.1:5000
