# 模型与运行环境说明

## 1. 深度学习模型

本项目使用预训练 ONNX 模型完成推理，不在课程实践阶段重新训练模型。

| 功能 | 模型 | 作用 |
| --- | --- | --- |
| 人脸检测 | YuNet | 在图片或摄像头帧中定位人脸框和关键点 |
| 人脸识别 | SFace | 提取人脸特征向量，并通过余弦相似度判断身份 |
| 反欺骗检测 | MiniFASNet | 判断输入更像真人脸还是照片、屏幕翻拍等攻击 |

这些模型让项目具备明确的深度学习元素：系统不是只做传统图像处理，而是使用深度神经网络完成检测、特征表达和活体反欺骗判断。

## 2. 模型文件位置

模型文件建议放在项目根目录的 `models/` 文件夹中：

```text
models/
  face_detection_yunet_2023mar.onnx
  face_recognition_sface_2021dec.onnx
  face_antispoof_minifasnetv2.onnx
```

如果自动下载失败，可以手动下载并放入该目录。

## 3. 运行环境

推荐环境：

- Python 3.11
- Windows 10 或 Windows 11
- 可用摄像头
- Chrome 或 Edge 浏览器
- 稳定的本地 Python 虚拟环境

安装依赖：

```powershell
pip install -r requirements.txt
```

如果 OpenCV 相关依赖安装失败，可先升级 pip：

```powershell
python -m pip install --upgrade pip
```

## 4. 识别阈值说明

人脸识别通常会设置相似度阈值。阈值过高会导致真人也难以识别成功，阈值过低会增加误识别概率。课程演示时可以根据摄像头光线、录入样本数量和现场距离进行适当调整。

反欺骗模型也有阈值限制。由于普通单目摄像头无法提供真实深度信息，本项目的反欺骗能力定位为课程演示级，主要用于降低静态照片和屏幕翻拍直接打卡的可能性，不等同于生产级 3D 活体检测。

## 5. 数据存储

系统默认把数据库和上传图片保存在本地 `instance/` 目录。演示完成后可以通过系统页面清理考勤记录和人员数据，也可以在确认不再需要后手动清理本地测试数据。
